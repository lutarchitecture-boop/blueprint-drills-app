# Blueprint Drills

A mobile practice-quiz app for the PPCE architecture exam: 386 multiple-choice questions across 9 themes, instant right/wrong feedback, short explanations, and per-theme score tracking saved on-device. Built as a [Capacitor](https://capacitorjs.com) app wrapping a self-contained, fully offline HTML/JS app (no network calls, no analytics, no accounts).

## How this repo is built

- `www/index.html` — the entire app: markup, styles, and the full 386-question bank, with all fonts bundled locally (`www/fonts/`) so it works with no internet connection at all.
- `android/` — the native Android project (generated by Capacitor) that wraps `www/` in a WebView.
- `assets/` — source icon/splash images and the script that generated them (`make_icons.py`).
- `build_www.py` — regenerates `www/index.html` from the design source and question bank (see below) if either changes.
- `.github/workflows/android-build.yml` — builds the app in GitHub's cloud on every push, no local Android SDK needed.

## Getting a build

Every push to `main` (or a manual run from the **Actions** tab → "Android build" → **Run workflow**) produces two downloadable files under that run's **Artifacts** section:

- **blueprint-drills-debug-apk** — install this directly on an Android phone to test (`app-debug.apk`). Android will warn about "unknown sources" since it's not from a store; that's expected for a test install.
- **blueprint-drills-release-aab-unsigned** — the release Android App Bundle (`app-release.aab`) that Play Console needs, but it is **unsigned**. You must sign it yourself before uploading (next section). Signing is deliberately not automated here — your signing key is what proves every future update is really from you, and only you should hold it.

## Signing the release build for Play Store

1. Generate your own upload key (one time, keep the output `.jks` file and its passwords somewhere safe and backed up — losing it means you can never update the app again under the same listing):
   ```
   keytool -genkeypair -v -keystore upload-key.jks -alias upload -keyalg RSA -keysize 2048 -validity 9125
   ```
2. Download `app-release.aab` from the Actions run.
3. Sign it, e.g. with [`jarsigner`](https://docs.oracle.com/javase/8/docs/technotes/tools/windows/jarsigner.html) or via Android Studio's **Build → Generate Signed Bundle / APK** wizard pointed at the downloaded `.aab` and your keystore.
4. Upload the signed `.aab` to [Play Console](https://play.google.com/console).

Play Console also offers to generate and manage the signing key for you ("Play App Signing") during your first upload — either path works; the key point is that this repo never holds or generates that key for you.

## Before you submit to Play Console

- **Privacy policy URL (required):** `docs/privacy.html` in this repo is a ready-to-use policy (the app collects no data; everything is stored locally on-device). Turn on **GitHub Pages** for this repo (Settings → Pages → Source: `main` branch, `/docs` folder) and you'll get a public URL like `https://<your-username>.github.io/<repo>/privacy.html` to paste into Play Console.
- **Content rights:** confirm you're clear to distribute the underlying exam questions commercially (you noted this is already settled on your end).
- **Disclaimer:** since the app references the PPCE exam, add a line in the store listing making clear this is an independent study tool and not an official ARCON/JBAE product, to avoid implying endorsement.
- **Pricing:** since this is a one-time paid download, you'll set the price directly in Play Console at upload time — no in-app billing code is needed for that model.
- **Store listing assets:** you'll need a 512×512 app icon (`assets/icon.png`, already the right size), a feature graphic (1024×500), and a few phone screenshots — happy to help generate these when you're ready.

## Local development (optional)

If you ever want to build locally instead of via CI, you'll need Node.js and the Android SDK (easiest via [Android Studio](https://developer.android.com/studio)):

```
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```
